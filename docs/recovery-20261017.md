# Shared-memory recovery, 17 October 2026

The kernel killed Distill-32B generation with global OOM at 09:36:31 and
09:41:54 Europe/Madrid. The latter victim was PID 886786, with about 51 GiB
anonymous resident memory. Swap was exhausted. The systemd service had reached
52 automatic restarts by 09:46.

At that point the concurrent `nemoclaw-vllm` container held 47,326 MiB of
GPU allocations on the shared-memory GB10. Stopping generation and that
container raised available system memory from about 11 GiB to 116 GiB.
The user authorized temporarily stopping vLLM and resuming the campaign.

## Resource scheduling

The campaign is resumed with:

```sh
env/bin/python scripts/run_campaign.py --config configs/study.json \
  --name study-20260925 --exclusive-vllm-container nemoclaw-vllm
```

For unfinished generation stages, the runner stops this container and confirms
it is stopped before launching the model. For judge validation and judging,
it starts the container and waits up to ten minutes for the expected model at
`http://127.0.0.1:8000/v1/models`. Completed stages are skipped before performing
any resource operations. Resource setup errors fail the campaign explicitly.

The local service has a drop-in at
`/home/ialab/.config/systemd/user/causal-fidelity-study.service.d/90-exclusive-vllm.conf`:

```ini
[Service]
ExecStart=
ExecStart=/home/ialab/jairo_experiments/causal-fidelity-cot/causal-fidelity-cot/env/bin/python scripts/run_campaign.py --config configs/study.json --name study-20260925 --exclusive-vllm-container nemoclaw-vllm
Restart=no
ExecStopPost=/usr/bin/docker start nemoclaw-vllm
TimeoutStopSec=180
```

This prevents another unattended restart loop and requests restoration of vLLM
on completion, failure, or an explicit service stop. Its dependent assistants
cannot use local inference while generation is running. The runner itself
does not restore vLLM on arbitrary interruption when used outside this service.

The service was restarted at 09:48:24 Europe/Madrid, resuming Distill-32B.
The completed 7B stages and all recorded attempts remain in campaign history.
